# Yashu Yang · Prototype Notes

这是我在 Trae on Campus 活动中完成的两个 AI 辅助交互原型，也是一次从生活经验、用户需求到可交互产品形态的快速验证。

## 项目

### 关系星系（Relationship Galaxy）

把难以复盘的亲密关系冲突转译成可记录、可观察、可共同讨论的互动旅程。原型包含对话记录、关系模式分析、内心地图和共同探索路径，关注冲突背后未被说出的需要。

### PFC Insight

把抽象的任务压力拆解为日程、任务切换成本与恢复节奏，用可视化界面呈现认知负荷。该项目是启发式概念模型，不构成医学评估、诊断或个体化建议。

## 我的工作

- 从日常经验中定义问题
- 进行需求拆解与用户路径设计
- 设计交互逻辑和功能优先级
- 使用 Trae 辅助编程完成 HTML 原型
- 根据体验结果继续修正产品假设

我主要承担问题定义、需求洞察、人文分析和产品规划。两个项目用于展示 AI 辅助原型能力，而非声称独立完成复杂工程开发。
